# The Google online store Analytics

Tools: 
Google Analytics 4 public dataset on the BigQuery platform using SQL queries.
Goal:
Calculated metrics and investigated their changes collected using Google Analytics 4.
Description:
prepared a dataset, calculated metrics - conversions, average time on the website, correlation between engagement and purchase.
Insights: 
- found events, sessions and users that can be used to build a report in BI systems.
- calculated conversions in terms of dates, channels and different landing pages, which made it possible to understand the effectiveness of the site.
- the low correlation between engagement and purchase suggests that there is no relationship between these events.
